# News Agent (API-Free Version)

An autonomous news analysis agent that runs without external APIs.

## Setup

1. Install dependencies: `npm install`
2. Run: `npm start`

## Features

- RSS feed monitoring (BBC, CNN, Reuters)
- Keyword-based impact scoring
- Console notifications
- Mock research and template-based articles
- PDF generation via Puppeteer
- Console delivery

## How It Works

- Monitors RSS feeds every 6 hours
- Scores articles based on keywords and impact indicators
- Notifies via console for high-impact items
- Generates articles using templates
- Outputs to console and PDF

No API keys or external services required!
